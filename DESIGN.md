# Design system

## Overview

Tools Directory is an instrument drawer: small utilities are indexed like workshop tools, with a search strip and a separate drawer card for adding the next one.

## Colors

- Workshop black: `#16191D`
- Index paper: `#EEF0F4`
- Acid label: `#E0EF68`
- Cobalt signal: `#2750AD`
- Orange mark: `#E57647`

## Typography

- Display and tool names: `Iowan Old Style`, `Palatino Linotype`, Georgia.
- Index labels, statuses, and counts: system monospace.
- Explanatory copy: Helvetica system sans.

## Layout

- Editorial hero with a physical drawer label.
- Dark drawer section contains search and a ruled instrument list.
- Add form returns to paper as a workshop card, not a generic modal.

## Elevation & Depth

The black drawer field is the depth cue. Acid labels and orange marks are flat ink signals.

## Shapes

Square sheets, ruled lines, and a compact label plate. No pill grid or floating card stack.

## Components

- Utility drawer bar
- Drawer label
- Search strip
- Instrument row
- New drawer card
- Empty drawer state

## Do's and Don'ts

- Do keep the index fast to scan and local-only claims explicit.
- Do make status a readable field, not decoration.
- Don't imply that entries launch or sync remote production tools.
- Don't turn a utility directory into a generic SaaS dashboard.
